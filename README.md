# Reset

An aesthetic stopwatch. Tap the dial to reset — every reset in the session stacks up
underneath, with a light bar showing its length relative to the longest one.
Built-in metronome (60 bpm default, adjustable bar length); resetting the dial
realigns it to a downbeat.

Single self-contained `index.html` — no build, no dependencies, no network calls.
Installable as a PWA from the hosted page.

**→ https://chixaelm.github.io/reset/**

## Merhaba Antalya

`turkish.html` — useful Turkish words and phrases for a trip to Antalya (146, in 9 topics),
each with an English-friendly respelling and tap-to-hear audio (uses the device's Turkish
voice). Six test styles run over each topic: meaning, recall, listening, letter sounds,
spelling, or a mix. Progress is saved on the device. Same deal: one file, no dependencies.

**→ https://chixaelm.github.io/reset/turkish.html**
